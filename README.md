# Laptop Data Analysis Dashboard

## 📌 Project Overview
This project presents an interactive dashboard built using Microsoft Excel to analyze laptop data and provide valuable insights into pricing, specifications, and laptop categories.

The dashboard enables users to explore the dataset through interactive filters and visualizations, making it easier to identify trends and compare laptop features.

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

---

## 📊 Dashboard Features
- Total Laptops
- Average Price
- Highest Price
- Average Price by Company
- Average Price by RAM
- Laptop Distribution by Type
- Interactive Filters (Company, Laptop Type, RAM, Operating System, CPU, GPU)

---

## 📈 Key Insights
- Premium laptops have the highest average prices.
- Devices with higher RAM generally have higher average prices.
- Notebook laptops represent the largest category in the dataset.
- Interactive slicers allow users to filter the dashboard by company, laptop type, RAM, operating system, CPU, and GPU.
